Планировщик задач

Веб-сервис для хранения задач с датой и правилом повторения.
Позволяет создавать, редактировать, удалять и отмечать выполненными задачи.
Просроченные задачи с повторением автоматически переносятся на следующую дату.
Есть веб-интерфейс и JSON API. Данные хранятся в SQLite.

Правила повторения:
- d N — каждые N дней (например d 7)
- y — раз в год
- w — по дням недели (например w 1,3,5)
- m — по числам месяца (например m 10,20)

Дополнительно добавлены:
- авторизация по паролю с JWT-токеном
- поиск задач по тексту и дате
- полные правила повторения w и m
- сборка через Docker

Запуск локально

Нужен Go 1.22+.

1. Перейдите в папку проекта и скачайте зависимости:
   go mod download

2. Запустите из корня проекта:
   go run main.go

Настроек-флагов нет, все через переменные окружения:
TODO_PORT — порт, по умолчанию 7540
TODO_DBFILE — файл базы, по умолчанию scheduler.db
TODO_PASSWORD — пароль для входа, по умолчанию пусто (без авторизации)

Пример запуска с паролем (PowerShell):
$env:TODO_PORT="7540"; $env:TODO_DBFILE="scheduler.db"; $env:TODO_PASSWORD="12345"; go run main.go

Пример .env:
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=12345

В браузере открыть:
http://localhost:7540

Запуск тестов

1. Запустите сервер и дождитесь сообщения о старте.
2. В отдельном терминале из корня проекта выполните:
   go test ./tests -v

Настройки в файле tests/settings.go должны совпадать с запущенным сервером:
Port = 7540
DBFile = ../scheduler.db
FullNextDate = true
Search = true
Token = пусто, если без пароля

Если сервер запущен с паролем, получите токен через POST /api/signin с паролем и вставьте его в Token, иначе тесты упадут с ошибкой авторизации.

Для полной проверки ставьте FullNextDate = true и Search = true.

Docker

Сборка из корня проекта:
docker build -t scheduler .

Запуск:
docker run -d -p 7540:7540 --name scheduler scheduler

С паролем:
docker run -d -p 7540:7540 --name scheduler -e TODO_PASSWORD=12345 scheduler

Открыть в браузере:
http://localhost:7540
